- Understanding of web development concepts
- Team collaboration
- Practical implementation skills
- Communication and presentation ability

  - Only one member presents.
  - Some members do not participate.
- Equal contribution is strongly encouraged.

---

## 🖥 Presentation Requirements

Each team must prepare a **PowerPoint/Google Slides presentation**.

### Recommended Slide Structure

1. **Title Slide**
   - Project Title
   - Team Members (Name & ID)
   - Course Name
   - Instructor Name

2. **Problem Statement**
   - What problem does your project solve?
   - Why is it important?

3. **Objectives**
   - Main goals of the system

4. **System Overview**
   - Brief explanation of the application
   - Target users

5. **Technology Stack**
   - Frontend (HTML, CSS, Bootstrap, etc.)
   - Backend (PHP, Node.js, etc.)
   - Database (MySQL, etc.)
   - Hosting Platform

6. **System Architecture**
   - Workflow diagram / system diagram
   - Database structure (ER Diagram if applicable)

7. **Features**
   - Main functionalities
   - User roles (if applicable)

8. **Live Demonstration**
   - Show working application
   - Show CRUD operations
   - Show authentication (if implemented)

9. **Challenges Faced**
   - Technical problems
   - Learning outcomes

10. **Future Improvements**
   - What can be improved later?

11. **Conclusion**

## 🌐 GitHub & Hosting Requirements

Each team must:

1. Upload the complete project source code to **GitHub**
   - Repository must be public.
   - Proper README.md file must be included.
   - Clear project structure must be maintained.

2. Host the project on a **free hosting platform**
   - Examples:
     - 000webhost
     - InfinityFree
     - Render
     - Railway
     - Vercel (for frontend)
   - Provide the live project URL during presentation.

Failure to upload code or host the project will result in mark deduction.
